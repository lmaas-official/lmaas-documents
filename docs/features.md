# 機能一覧

最終確認日: 2026-11-12 ／ 出典: https://lmaas.io/ja （「lmaas.ioでできること」「ほかにもこんな特徴があります」）

## AIを使う

| 機能 | 内容 |
|---|---|
| AIチャット | 利用者が日常の業務でAIを使えます（文章作成・要約・アイデア整理・調査など） |
| チャットボット・API連携の用意 | チャットボットや、システム連携に使うAPIを、画面のボタン操作で用意できます |
| 推論エンジンの切り替え | 使いたいモデルに合わせて、AIを動かす仕組み（推論エンジン）を切り替えられます（GPU占有プランで対応。プラン別は [plan-matrix](../specs/plan-matrix.md)） |

## AIモデルを選ぶ

| 機能 | 内容 |
|---|---|
| 1,000種類以上のモデル | AIモデルの公開サイト「Hugging Face」から選んだモデルを、選ぶだけで使えます |
| 有名企業のオープンモデル | Google「Gemma」、OpenAI「gpt-oss」、Meta「Llama」、Alibaba「Qwen」など（各社が公開しているオープンモデルです） |
| 業務・業種での絞り込み | 「問い合わせ対応」「文書要約」などの業務や、「医療」「保険」などの業種で探せます |
| 利用条件の表示 | 「商用利用」「追加学習」「再配布」ができるかを、モデルごとに表示します |
| 同意の記録 | モデルごとのライセンスへの同意について、同意した人と日時を記録します |

## 社内データを使う（RAG）

| 機能 | 内容 |
|---|---|
| 社内文書の参照 | PDFなどの社内文書を登録すると、AIがその内容を検索・参照して答えます。全プランに搭載 |
| 辞書データの版管理 | AIが参照する辞書データ（RAG）を版ごとに管理します |
| RAGだけの反映 | 追加学習をせずに、RAGの辞書データだけを更新することもできます |

## AIを育てる（追加学習・LoRA）

| 機能 | 内容 |
|---|---|
| 追加学習 | AIモデル本体は変えずに、小さな「追加の部品」（LoRA）だけを学習させます。登録したQ&Aや文章の答え方・書き方をなぞるように覚えます |
| かんたんな設定 | 学習データを登録して、学習強度を「低」「標準」「高」の3段階から選ぶだけ。学習の処理は自動で実行され、進み具合を画面で確認できます |
| 学習結果の版管理 | 育てたAIを版ごとに保存します。結果が思わしくなければ、前の版に切り替えられます |
| 元のモデルに戻す | 育てた版を使うのをやめて、元のモデルだけの状態に戻せます |
| 学習履歴の一覧 | 学習の経過を一覧で確認できます |
| チャット中の学習 | AIをチャットで使っている間も学習を進められます。学習が終わると、最新の版を使えます |
| 学習専用モード | GPU占有プラン（Starter Plus・Business Plus）では、チャットに使っているサーバーを学習専用に切り替えて、回数の制限なしに学習できます（その間はチャットなどに使えません） |

## つなぐ

| 機能 | 内容 |
|---|---|
| API連携 | 自社のWebサービスや業務システムから、lmaas.io のAIを呼び出せます（[integrations](integrations.md)） |
| MCP連携 | AIから外部のサービスや社内システムへ接続し、必要な情報を取得してまとめさせられます（[integrations](integrations.md)） |

## 管理する

| 機能 | 内容 |
|---|---|
| お客様ごとの環境 | お客様単位でAIの利用環境を分け、他のお客様の環境と混ざらない構成を基本にしています |
| 役割の分離 | 管理者だけが設定を変更でき、利用者は割り当てられたAIや接続先だけを使えます |
| 利用者ごとのアクセス制御 | AIからのアクセスや、外部システムへつなぐMCPを、利用者ごとに設定できます |
| 外部接続の許可制 | 外部サービスとの接続は管理者だけが登録し、使える利用者も管理者が決めます |
| チャット履歴の確認 | Business・Business Plus では、管理者が利用者全員の会話（API経由を含む）を確認できます（不正利用の防止・監査のため） |
| AI生成の記録 | AIが回答を作るたびに、署名付きの生成記録を作ります（[security](security.md)） |

## 使い始め

- サービス開通後、最短10分で専用AIを使い始められます（目安です）。
