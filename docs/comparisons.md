# ほかの選択肢との違い

最終確認日: 2026-11-12

生成AIを業務に使う方法はいくつかあります。それぞれの考え方の違いを整理します。特定の他社サービスの性能や機能を評価するものではありません。各社の名称・商標は各社に帰属します。

## 比べる選択肢

| | 汎用AIチャットサービス（ChatGPT・Gemini など） | 自社でGPUサーバーを用意してオープンモデルを動かす | lmaas.io |
|---|---|---|---|
| 一般的な質問・文章作成 | ◎ | 選んだモデルによる | ○（選んだモデルによる） |
| 社内文書の検索・参照 | △ | 自社で仕組みを作る | ◎（RAGを全プランに搭載） |
| 自社の言い回し・専門用語への対応 | △ | 自社で学習の仕組みを作る | ◎（追加学習・版管理） |
| 外部のAIサービスにデータを送らない | 送る | 送らない | 送らない（外部接続を設定した場合を除く） |
| GPUサーバーの用意・保守 | 不要 | 必要 | 不要 |
| AIモデルの選択 | サービスが提供するモデル | 自由 | 1,000種類以上から選択（プランごとに大きさの上限あり） |
| 利用者・接続先の管理 | サービスのプランによる | 自社で作る | 管理者が利用者・接続先を管理 |
| 費用の形 | 利用者数や利用量に応じた料金が多い | 機材・電気代・保守の人件費 | 月額固定（別途初期費用） |

表は考え方の目安です。◎・○・△は、各サービスの性能の優劣を示すものではありません。

## lmaas.io を選ぶ理由になりやすいこと

- 社内文書や顧客情報を、外部のAIサービスに送りたくない
- オープンモデルを使いたいが、GPUサーバーの準備・保守はしたくない
- 社内文書の参照と追加学習で、自社向けのAIを育てたい
- 費用を月額固定で見通したい

## ほかの選択肢のほうが合いやすいこと

- 最新・最大級の汎用AIの性能を最優先する場合は、汎用AIチャットサービスが向いています
- モデルの大きさや構成を完全に自由にしたい、社内のネットワークの中だけで動かしたい場合は、自社でGPUサーバーを用意する方法が向いています（lmaas.io はクラウドのサービスです）
- 少人数で、扱う情報に機密性がない場合は、汎用AIチャットサービスのほうが費用を抑えやすいことがあります

## lmaas.io のプラン同士の比べ方

| 決め手 | 選び方 |
|---|---|
| 使いたいモデルの大きさ | 4B級→Personal、8B級→Starter・Starter Plus、24B級→Business、32B級→Business Plus |
| 返答の速さ | 安定した速さが必要なら GPU占有（Starter Plus・Business Plus） |
| 利用者数 | Personal 1人、Starter 3人、Starter Plus・Business 10人まで |
| 管理者による会話の確認 | Business・Business Plus のみ |
| 学習の頻度 | 多いなら学習専用モードを使える GPU占有プラン |
