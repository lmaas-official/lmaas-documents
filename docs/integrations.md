# 連携（API・MCP）

最終確認日: 2026-11-12 ／ 出典: https://lmaas.io/ja#integrations

lmaas.io のAIは、チャット画面の中だけでなく、お客様の業務システムや外部サービスとつなげて使えます。

## API連携 — 既存のシステムからAIを使う

自社のWebサービスや業務システムから、lmaas.io のAIを呼び出せます。

| 項目 | 内容 |
|---|---|
| 呼び出し方 | HTTPS で、JSON 形式のリクエストを送ります |
| 返事の形式 | OpenAI 互換の JSON 形式です。ただし呼び出し先のアドレスは OpenAI の公式SDKが前提とするものと異なるため、公式SDKはそのまま使えません。HTTPのリクエストを直接組み立てて使います |
| 認証 | APIキーを使います。APIキーの発行・失効は管理者だけが行えます |
| 使えるモデル | お客様の環境に登録したモデル（学習した版を含む） |
| AI生成の印 | 返事に、AIが生成したことを示す印と、生成記録の番号が付きます |
| 会話の確認 | Business・Business Plus では、API経由の会話も管理者が確認できます |

具体的な呼び出し方とサンプルは、ご契約後の画面（ヘルプ・外部接続の画面）で案内しています。

**使い方の例**
- お問い合わせフォームに届いた内容をAIが要約して、社内の管理システムへ登録する（[例](../examples/inquiry-workflow.md)）
- 顧客データベースの情報をAIが読み取って、回答の下書きを作る

## MCP連携 — AIに仕事を進めてもらう

MCP（Model Context Protocol）は、AIが外部のサービスや社内システムに接続して、情報の取得や操作を行うための共通の仕組みです。lmaas.io では、AIから外部の道具（AI用ツール）を使えるようにできます。

| 項目 | 内容 |
|---|---|
| 接続先の登録 | 管理者だけが登録できます |
| 使える利用者 | 管理者が利用者ごとに決めます |
| データの扱い | 接続先へデータが送られます。接続先での扱いは lmaas.io の安全の範囲外です |
| 回答の能力 | モデルによって差があり、正しくない回答をすることがあります |

**使い方の例**
- 予定表・問い合わせ管理ツール・社内資料から情報を集めて、「今週の対応状況」を報告書にまとめる

> AIからインターネットなどの外部サービスへ接続すると、情報が外に出るリスクが高まります。接続先は必要なものだけに絞ってください。

## チャットボット

チャットボットや、システム連携に使うAPIを、画面のボタン操作で用意できます。
