# 安全性とデータの扱い

最終確認日: 2026-11-12 ／ 出典: https://lmaas.io/ja#trust 、https://lmaas.io/ja/terms 、https://lmaas.io/ja/privacy

この資料は概要です。正式な取り決めは利用規約とプライバシーポリシーに従います。

## lmaas.io が行っていること

### データを外部のAIサービスに送らない

- 資料・学習データ・会話は lmaas.io の環境の中で処理し、ChatGPT などの外部AIサービスへは送りません。
- AIの計算は、当社が契約するクラウドGPU事業者の設備上で行います。
- **例外:** お客様が外部接続（MCP・API）を設定した場合は、その接続先にデータが送られます。外部接続の先での扱いは、接続先のサービスの条件によります。

### お客様ごとに環境を分ける

- お客様単位でAIの利用環境を分け、他のお客様の環境と混ざらない構成を基本にしています。
- 共有GPUのプランでは、GPU（計算機）を複数のお客様で共有し、依頼の順に処理します。

### 保存するデータを暗号化する

- お客様の学習用データや学習済みのデータは、暗号化して保存しています。

### 管理者が利用を管理する

- 設定の変更は管理者だけが行えます。利用者は割り当てられたAIや接続先だけを使えます。
- 外部サービスとの接続は管理者だけが登録し、使える利用者も管理者が決めます。
- Business・Business Plus では、管理者が利用者全員の会話（API経由を含む）を確認できます。利用者が自分で会話を削除しても、利用者の画面から消えるだけで、管理者は削除から180日間確認できます。Personal・Starter・Starter Plus にこの機能はありません。

### AIモデルのライセンスを確認する

- 当社は、AIモデルを掲載する前にライセンスなどを確認しています。
- 「商用利用」「追加学習」「再配布」ができるかをモデルごとに表示し、ライセンスへの同意を、同意した人と日時とともに記録します。

### AIが作ったことを分かるようにする

- チャット画面には、AIと会話していることを常に表示します。
- AIには、人間かと尋ねられたらAIであると答えるよう、あらかじめ指示しています。
- 外部のシステムからAPIで使う場合も、返事にAIが生成したことを示す印を付けます。
- AIが回答を作るたびに、署名付きの生成記録を作ります。記録には回答の文章そのものは含めず、照合のための指紋（ハッシュ）を保存します。記録は作成から180日間保存し、その後は自動で削除します。
- 照合窓口に文章を送ると、lmaas.io のAIが作った回答かどうかを確認できます。文章が書き換えられていると見つからないことがあり、見つからなかったことは「AIが作っていない」ことを示すものではありません。
- これらは、EUのAI規制（EU AI Act）第50条が求める、AIの告知とAI生成物の識別に対応した機能です。サービスやお客様の利用が、EUの法令に適合することまでを示すものではありません。

## lmaas.io が保証しないこと

導入の判断に必要なため、保証しない範囲も明記します。

- **AIの回答の正確さ。** AIは必ずしも正確な回答を生成するとは限りません。lmaas.io はAIの利用環境を提供するもので、回答の正確さや特定の目的への適合性を保証しません。
- **AIモデル・学習させたAIの安全性。** 有害な内容や誤った内容を出力しないこと、意図しない動作をしないことまでは保証できません。業務で使う前に、お客様ご自身で出力の内容や安全性を確認してください。
- **MCPやAI用ツールを使った回答の能力。** モデルによって差があり、正しくない回答をすることがあります。
- **返答の速さ。** 利用状況や外的な要因で変わるため、プランを問わず保証しません。
- **外部接続の先での安全性。** お客様が設定した外部接続（MCP・API）の先は、lmaas.io の安全の範囲外です。

## モデルの提供停止について

- AIモデルの提供元によるライセンスの変更や提供停止、安全性の問題などにより、一部のモデルが使えなくなることがあります。
- 当社が保有するライセンスと、お客様が同意するライセンスは分けて管理しています。
