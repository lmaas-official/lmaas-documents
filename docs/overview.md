# lmaas.io の概要

最終確認日: 2026-11-12 ／ 出典: https://lmaas.io/ja （トップページ）

## lmaas.io とは

lmaas.io は、お客様が生成AIを安心して業務に使うための、AI（LLM）の利用環境をまとめて提供するクラウドサービスです。AIモデルの利用、社内データとの連携、AIのカスタマイズ（追加学習）、利用者の管理までを、お客様ごとに分けられた環境の中で行えます。

一般的な生成AIサービスは「AIを使うこと」が中心です。lmaas.io は **お客様 × AIモデル × 社内データ × 利用者** を、お客様専用の環境として提供します。

## 背景にある課題

生成AIを業務に使いたいお客様からは、次のような声があります。

- 社内文書を生成AIに入力してよいのか、わからない
- 顧客情報や機密情報の扱いが心配
- 社員が個別にAIサービスを使ってしまっている
- 社内のIT担当者だけでは、AIの管理が難しい
- 社内規程やマニュアルを、AIに答えさせたい
- 自社専用のAIを作りたい

## lmaas.io の考え方

### 1. 外部のAIサービスにデータを送らない

資料・学習データ・会話は lmaas.io の環境の中で処理し、ChatGPT などの外部AIサービスへは送りません。ただし、お客様が外部接続（MCP・API）を設定した場合は、その接続先に送られます。

### 2. AIを「選ぶ」だけでなく「育てる」

ChatGPT や Gemini のような汎用AIは優れていますが、お客様の社内規程・業務手順・製品知識・過去の事例・専門用語は、最初から知りません。lmaas.io では次の組み合わせで「自社の業務を理解したAI」を目指します。

- 公開されているAIモデルの力
- 社内文書の検索・参照（RAG）
- 自社データでの追加学習（LoRA）
- 必要に応じたAIモデルの選び直し

### 3. 段階的に広げられる

1. まずはAIチャットとして使う
2. 社内文書を登録して、RAGで参照させる
3. 業務データで追加学習し、自社向けに育てる
4. API・MCPで業務システムとつなげる

## lmaas.io が目指していないこと

lmaas.io は、ChatGPT や Gemini そのものと性能を競うサービスではありません。一般的な質問や文章作成の性能は、選んだAIモデルによります。
