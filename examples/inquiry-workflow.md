# 利用例: お問い合わせの要約を社内システムへ登録する

> 機能の使い方を説明するための想定例です。会社名・内容は架空です。特定のお客様の導入事例ではありません。

## 想定する状況

- 部品メーカーA社（架空）には、Webのお問い合わせフォームから1日に数十件の問い合わせが届く
- 担当者が本文を読み、種類を分けて要約し、社内の案件管理システムへ手で入力している
- 問い合わせには顧客の社名・担当者名・取引の内容が含まれるため、外部のAIサービスには送りたくない

## 流れ

```
お問い合わせフォーム
      │ ① 問い合わせが届く
      ▼
A社の業務システム
      │ ② 本文を lmaas.io のAPIへ送る（APIキーで認証）
      ▼
lmaas.io（A社専用の環境）
      │ ③ AIが要約・種類分けの下書きを返す（AI生成の印つき）
      ▼
A社の業務システム
      │ ④ 結果を案件管理システムへ登録
      ▼
担当者が内容を確認して対応
```

## 設定の手順（概要）

1. 管理者が lmaas.io で使うAIモデルを選ぶ
2. 必要に応じて、過去の問い合わせと分類の例で追加学習（LoRA）を行い、A社の分類の仕方を覚えさせる
3. 管理者がAPIキーを発行する
4. A社の業務システムから、APIを呼び出す処理を組み込む

## AIへの依頼文の例

```
次のお問い合わせを、以下の形式でまとめてください。
・種類（見積もり／納期／不具合／その他）
・要点（3行以内）
・急ぎかどうか

お問い合わせ本文：
（ここに本文）
```

## 注意点

- AIの要約や分類は誤ることがあります。担当者が確認してから対応してください
- 件数が多い・返答の速さが必要な場合は、GPU占有プラン（Starter Plus・Business Plus）が向いています
- 問い合わせ本文は lmaas.io の環境の中で処理され、外部のAIサービスへは送られません
