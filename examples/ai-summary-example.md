# 利用例: 社内文書をもとにした回答と要約

> 機能の使い方を説明するための想定例です。会社名・規程の内容は架空です。AIの実際の出力は、選んだモデル・登録した資料によって変わります。

## 想定する状況

- B社（架空）の総務部には、出張旅費の精算について同じ質問が繰り返し届く
- 「出張旅費規程」（PDF）を lmaas.io に登録し、RAG で参照させている

## 質問と回答の例

**利用者の質問**

```
日帰り出張でも日当は出ますか？
```

**AIの回答（例）**

```
出張旅費規程 第8条によると、日帰り出張の場合も、片道の移動距離が
100km以上であれば日当が支給されます。100km未満の場合は支給されません。
金額は同条の別表をご確認ください。
（参照: 出張旅費規程.pdf）
```

※ 規程の条文・数値は架空です。

## 要約の例

**利用者の依頼**

```
出張旅費規程を、新入社員向けに5行で要約してください。
```

**AIの回答（例）**

```
1. 出張は事前に上長の承認を得て申請します。
2. 交通費は、原則として最も経済的な経路の実費を精算します。
3. 宿泊費は、役職ごとの上限額の範囲で実費を精算します。
4. 一定の距離以上の出張には日当が支給されます。
5. 精算は出張終了後、所定の期限までに申請します。
```

## このように使うためのポイント

- 規程を改定したら、RAGの辞書データだけを更新できます。前の版にも戻せます
- 答え方の書式（参照元を必ず書く、など）を揃えたい場合は、回答例で追加学習（LoRA）を行うと効果的なことがあります
- AIの回答は誤ることがあります。重要な判断は、元の規程で確認してください
