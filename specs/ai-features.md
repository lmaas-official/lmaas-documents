# AI機能の仕様

最終確認日: 2026-11-14

## AIモデル

| 項目 | 内容 |
|---|---|
| モデルの種類 | 公開されているオープンなLLM（大規模言語モデル） |
| 掲載数 | 1,000種類以上（AIモデルの公開サイト「Hugging Face」から選んだもの） |
| 主な開発元 | Google（Gemma）、OpenAI（gpt-oss）、Meta（Llama）、Alibaba（Qwen）など |
| 探し方 | 業務（問い合わせ対応・文書要約など）、業種（医療・保険など）で絞り込み |
| 利用条件の表示 | 商用利用・追加学習・再配布の可否をモデルごとに表示 |
| ライセンスの同意 | 同意が必要なモデルは、同意した人と日時を記録 |
| 大きさの上限 | プランごとに「〇B級」（モデルの表示上の大きさ）と、GPUに載る重さの両方で判定します（[plan-matrix](plan-matrix.md)） |
| AI実行エンジン | Ollama（全プラン）、vLLM（GPU占有プランで切り替え可能） |

「〇B級」は、モデル名に付く大きさ（例: 8B）を目安にした区分です。名前は8Bでも実際の大きさが少し大きいモデルがあるため、画面には実際の大きさも表示します。

## 社内文書の参照（RAG）

| 項目 | 内容 |
|---|---|
| 方式 | RAG（検索拡張生成）。登録した文書から関連する部分を検索し、AIが回答に使います |
| 対象プラン | 全プラン |
| 版管理 | 辞書データを版ごとに管理し、版を選んで使えます |
| 更新 | 追加学習をせずに、RAGの辞書データだけを更新できます |

## 追加学習（LoRA）

| 項目 | 内容 |
|---|---|
| 方式 | LoRA。AIモデル本体は変えずに、小さな「追加の部品」だけを学習します |
| 覚える内容 | 登録したQ&Aや文章の答え方・書き方 |
| 1件の長さ | 約2,000トークンまで（それより長い部分は切り捨て） |
| 設定 | 学習強度を「低」「標準」「高」の3段階から選ぶだけ。学習は自動で実行されます |
| 回数 | 30日ごとにプラン別の回数（Personal・Starter・Starter Plus 5回、Business 8回、Business Plus 10回）。1回800円（税別）で追加可能 |
| 学習専用モード | GPU占有プランでは、サーバーを学習専用に切り替えて回数の制限なく学習できます（その間はチャット不可） |
| 版の保存数 | Personal 3、Starter・Starter Plus 5、Business 7、Business Plus 10 |
| 戻す | 前の版、または元のモデルだけの状態に戻せます |
| 学習できないモデル | 圧縮された形式など、学習できないモデルがあります。画面で学習の可否を表示します |

## AI生成の識別

| 項目 | 内容 |
|---|---|
| 画面の表示 | AIと会話していることを常に表示 |
| APIの返事 | AIが生成したことを示す印と記録番号を付与 |
| 生成記録 | 回答ごとに署名付きの記録を作成。回答の文章そのものは含めず、照合用の指紋を保存。180日間保存 |
| 照合 | 照合窓口で、lmaas.io のAIが作った回答かを確認可能 |

## モデルごとの追加学習（LoRA）とAI実行エンジンの関係

lmaas.io で「追加学習」を使うときに、よくある疑問をまとめます。

### 学習と、返事を出す仕組みは別々です

- **学習**（LoRAという「追加の部品」を作る作業）は、学習専用のGPUサーバーで行います。
- **返事を出す仕組み**（AI実行エンジン）は、Ollama または vLLM です。学習で作った部品を、チャットで使えるように組み込みます。
- 学習の仕組みは、Ollama・vLLM のどちらを選んでも同じです。エンジンを切り替えても、学習のやり方は変わりません。

### 学習した部品の組み込み方は、エンジンで違います

| AI実行エンジン | 組み込み方 | 補足 |
|---|---|---|
| Ollama | 学習した部品をOllama用の形式に変換して、元のモデルに組み込みます | 全プランで使えます。変換と組み込みは自動で行われ、お客様の操作は不要です |
| vLLM | チャットのときに、学習した部品を実行時に読み込みます | GPU占有プランで切り替えられます。変換は不要です |

どちらのエンジンでも、学習済みの部品はお客様ごとに分けて管理され、ほかのお客様のAIには使われません。

### 学習できるモデル・できないモデル

| モデルの種類 | 追加学習 | 社内文書の参照（RAG） |
|---|---|---|
| 通常の公開モデル（Llama系、Qwen系など） | できます | 使えます |
| 圧縮された形式のモデル（FP8・AWQ・GPTQ など） | できません | 使えます |
| 圧縮された形式（GGUF）だけで公開されているモデル | できません | 使えます |

- 圧縮された形式は、モデルを軽くするために精度を落として小さくしたものです。チャットには使えますが、追加学習には元の精度が必要なため、学習の予約の時点でお断りします。
- 学習できないモデルでも、社内文書の参照（RAG）だけを使うことができます。
- 新しく公開されたモデルは、学習に対応しているかどうかが分からないことがあります。学習できるかどうかは、モデルごとに画面に表示します。

### 続きから学習するには

- 一度作った追加学習の版をもとに、続きから学習できます（継続学習）。
- 続きから学習するときは、前の版の学習結果をもとにします。前の版を削除すると、その版からの続きの学習はできなくなります。
- 前の版に戻したり、元のモデルだけの状態に戻したりすることは、いつでもできます。

### 注意してほしいこと

- 追加学習の効果は、選んだモデルや学習データの内容によって変わります。効果は保証しません。
- モデルが新しいほど、Ollama・vLLM の対応状況や学習への対応が、まだ整っていないことがあります。対応状況は画面で確認してください。
