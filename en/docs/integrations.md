# Integrations (API and MCP)

Last checked: 2026-11-12 (Japanese original) / Source: https://lmaas.io/#integrations

lmaas.io's AI can be used not only inside the chat screen but also connected to your business systems and external services.

## API integration — use AI from your existing systems

Call lmaas.io's AI from your own web services and business systems.

| Item | Details |
|---|---|
| How to call | Send JSON requests over HTTPS |
| Response format | OpenAI-compatible JSON. However, the endpoint address differs from what the official OpenAI SDK assumes, so the official SDK cannot be used as is. Build the HTTP requests directly |
| Authentication | API keys. Only administrators can issue and revoke API keys |
| Available models | Models registered in your environment (including trained versions) |
| AI generation marker | Replies carry a marker showing that they were generated by AI, and the number of the generation record |
| Conversation review | On Business and Business Plus, administrators can also review conversations made via API |

Concrete instructions and samples are provided on the screens available after you sign up (help and external connection screens).

**Examples**
- Have the AI summarize inquiries received through a contact form and register them in an internal management system ([example](../examples/inquiry-workflow.md))
- Have the AI read information from a customer database and draft replies

## MCP integration — let the AI move your work forward

MCP (Model Context Protocol) is a common mechanism that lets AI connect to external services and internal systems to retrieve information and perform operations. With lmaas.io, you can let the AI use external tools (AI tools).

| Item | Details |
|---|---|
| Registering destinations | Only administrators can register them |
| Users allowed | Administrators decide for each user |
| Data handling | Data is sent to the destination. How it is handled there is outside the scope of lmaas.io's security |
| Answer capability | It varies by model, and the AI may give incorrect answers |

**Example**
- Gather information from calendars, inquiry management tools and internal documents, and summarize "this week's status" into a report

> Connecting the AI to external services such as the internet increases the risk of information leaving your company. Limit connections to only what is necessary.
